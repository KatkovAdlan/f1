# История изменений XtoXray

## 1.0.0-neoforge.15 (пока не выпущено)

### Исправлено
- Переработано удаление солнца и луны во время X-Ray.
- Вмешательство перенесено с временной замены исходных `static final` полей на перехват их чтения внутри `LevelRenderer.renderSky()`.

### Технические изменения
- Сохранены оригинальные ссылки Minecraft на текстуры солнца и луны.
- При активном X-Ray вместо них используется прозрачная текстура XtoXray.
- Изменение сделано отдельным коммитом, чтобы его можно было легко проверить или откатить.

### Версия
- Версия мода увеличена с `1.0.0-neoforge.14` до `1.0.0-neoforge.15`.

### Тестовое окружение
- Добавлен отдельный тестовый профиль `XtoXray_Test` для PineconeMC/ElyPrism.
- Тестовый профиль собирается на базе `Gregnautics`, но не использует сохранения основного мира.
- Моды синхронизируются в тестовый профиль через жёсткие ссылки; `XtoXray` устанавливается свежей сборкой после каждого запуска `test.bat`.
- Advanced XRay исключён из тестового профиля, чтобы он не вмешивался в проверку рендера XtoXray.
- Добавлен автоматический стенд с ванильными рудами и динамическим поиском рудоподобных блоков в реестре модифицированной сборки.
- Добавлена открытая зона для отдельной проверки солнца и луны.
