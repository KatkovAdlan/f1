# История изменений XtoXray

## 1.0.0-neoforge.16 (пока не выпущено)

### Исправлено
- Исправлено отображение версии в интерфейсе XtoXray: теперь она берётся непосредственно из информации о загруженном моде NeoForge.
- Переработано скрытие солнца и луны во время X-Ray: вместо перехвата чтения `static final` полей перехватывается привязка текстур внутри `LevelRenderer.renderSky()`.

### Технические изменения
- NeoForge передаёт `ModContainer` в конструктор мода, а интерфейс использует фактическую версию из `ModInfo`.
- При активном X-Ray вызов `RenderSystem.setShaderTexture()` для исходных текстур солнца и луны заменяется на прозрачную текстуру XtoXray.
- Исходные ссылки Minecraft на текстуры солнца и луны не изменяются.
- Изменения сделаны отдельными коммитами, чтобы их можно было легко проверить или откатить.

### Версия
- Версия мода увеличена с `1.0.0-neoforge.15` до `1.0.0-neoforge.16`.

### Тестовое окружение
- Добавлен отдельный тестовый профиль `XtoXray_Test` для PineconeMC/ElyPrism.
- Тестовый профиль создаётся на базе `Gregnautics`, но не использует сохранения основного мира.
- Моды синхронизируются в тестовый профиль через жёсткие ссылки.
- `XtoXray` устанавливается свежей сборкой после каждого запуска `test.bat`.
- Advanced XRay исключён из тестового профиля, чтобы он не вмешивался в проверку рендера XtoXray.
- Добавлен автоматический стенд с ванильными рудами и динамическим поиском рудоподобных блоков в реестре модифицированной сборки.
- Добавлена открытая зона для отдельной проверки солнца и луны.
- Старый датапак тестового мира оставлен в репозитории как резервный, но `test.bat` его больше не использует: генерацией тестовой площадки занимается отдельный KubeJS-скрипт.
- Скрипт сборки `build.bat` поддерживает режим `/nopause` для автоматического тестового запуска.
