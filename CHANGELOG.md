# История изменений XtoXray

## 1.0.0-neoforge.14 (пока не выпущено)

### Исправлено
- Переработано удаление солнца и луны во время X-Ray.
- Вмешательство перенесено с временной замены исходных `static final` полей на перехват их чтения внутри `LevelRenderer.renderSky()`.

### Технические изменения
- Сохранены оригинальные ссылки Minecraft на текстуры солнца и луны.
- При активном X-Ray вместо них используется прозрачная текстура XtoXray.
- Изменение сделано отдельным коммитом, чтобы его можно было легко проверить или откатить.

### Версия
- Версия мода увеличена с `1.0.0-neoforge.13` до `1.0.0-neoforge.14`.

### Тестовое окружение
- Добавлен `test.bat` для сборки свежего JAR и запуска отдельной инстанции `XtoXray_Test` через PineconeMC/ElyPrism.
- Тестовая инстанция создаётся отдельно от `Gregnautics`; моды переиспользуются через жёсткие ссылки, чтобы не создавать полную копию файлов.
- Добавлен тестовый датапак для небольшого мира с ограниченной границей и набором ванильных руд.
